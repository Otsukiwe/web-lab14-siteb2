# Лабораторная работа №14

Использование cookie и журнал посещения страниц на PHP. Исходный каркас взят из `siteb2.zip`.

## Запуск в Open Server Panel

1. Скопировать папку `siteb2` в `C:\OSPanel\home`.
2. Запустить или перезапустить Open Server Panel. Конфигурация домена находится в `siteb2/.osp/project.ini`: Apache и PHP 8.0.
3. Открыть <http://siteb2.loc/>.

На компьютере, где выполнена работа, проект установлен в `C:\OSPanel\home\siteb2`.

## Что реализовано

- `inc/cookie.inc.php`: чтение `visitCounter` и `lastVisit`, установка cookie до вывода HTML. Счётчик увеличивается один раз за календарный день, часовой пояс — Екатеринбург. Cookie хранятся год.
- `index.php`: приветствие при первом визите, счётчик и дата предыдущего учтённого визита при последующих запросах, пункт меню «Журнал посещений».
- `inc/log.inc.php`: каждый запрос записывается отдельной строкой `timestamp|REQUEST_URI|HTTP_REFERER` в `log/path.log`. При прямом переходе Referer пустой. Запись выполняется с блокировкой файла.
- `inc/view-log.inc.php`: проверка наличия файла, чтение массива строк, вывод списка с датами и HTML-экранированием адресов.
- `inc/headers.inc.php`: стандартный открывающий тег PHP и обработка отсутствующего параметра `id` без предупреждения.

Журнал создаётся автоматически, его содержимое не включается в Git.

## Проверка

Все PHP-файлы прошли `php -l` на PHP 8.0.30. Через HTTP проверены первый визит, повторный запрос с теми же cookie, переход на следующий день с тестовыми cookie, все пункты меню, передача Referer, формат строк и отображение журнала. Все проверки прошли.

Для ручной проверки открыть сайт и обновить страницу: за один день счётчик остаётся прежним. Пройти по пунктам меню и открыть «Журнал посещений».
